## Contributing

We welcome public contributions to Project AIM — bug reports, pull requests, and feature suggestions help improve the project for everyone.

- To report bugs, please use the Bug Report template: .github/ISSUE_TEMPLATE/bug_report.md
- To suggest new features, use the Feature Request template: .github/ISSUE_TEMPLATE/feature_request.md
- For code contributions, please read CONTRIBUTING.md for guidelines on forking, branching, testing, and opening pull requests.

If you discover a security vulnerability, please contact the repository owner privately so it can be addressed before public disclosure.
